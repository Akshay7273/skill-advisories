# Benchmarks

Benchmark results in this directory are generated by `scripts/benchmark.mjs`.
The corpus contains deterministic synthetic names and files; setup time is not
included in the measured filesystem scan. The false-positive sweep checks
100,000 generated benign identities against every name in the committed public
feed and records both warning count and rate.

Run the CI-sized regression benchmark:

```sh
npm run benchmark:ci
```

Run the v0.6 release-candidate corpus and save a result:

```sh
npm run benchmark -- --identities 100000 --artifacts 10000 \
  --output benchmarks/results/<platform>-<node>.json
```

Results are evidence for a specific commit and environment, not universal
performance guarantees. Compare like-for-like corpus parameters and runtime
environments. Pull requests should use the CI regression ceilings instead of
regenerating committed release results.
