# Maintainer operations

These runbooks define the minimum auditable response for routine changes and
security incidents. Commands are examples; maintainers must record the issue,
pull request, commit, actor, timestamps, and verification output used in an
actual event.

- [Advisory triage](triage.md)
- [Corrections and withdrawals](correction.md)
- [Release procedure](release.md)
- [Compromised release response](incident.md)
- [Last-known-good feed recovery](rollback.md)

Security-sensitive discussion may begin privately using the process in
[`SECURITY.md`](../../SECURITY.md). Public records should be created as soon as
disclosure no longer increases risk.
